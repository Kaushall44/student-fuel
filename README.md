# Student Fuel frontend

A frontend-only React + TypeScript + Vite cafe ordering experience for Student Fuel, Bundu, Ranchi.

## Run locally

```bash
npm install
npm run dev
```

## Included

- Responsive landing page, menu, combo detail, cart, checkout demo, success, about, contact and 404 routes
- The six supplied combo items and prices
- Search, add-to-cart, quantity controls and localStorage cart persistence
- Checkout form validation and a clearly labelled demo confirmation (no order is transmitted)
- Delivery information: free up to 3 km; ₹20 extra for 3–5 km; minimum order ₹99; availability depends on location

## Before going live

- Replace the sample food photography with real Student Fuel product photos.
- Confirm actual menu, delivery coverage, opening hours and any applicable delivery charges.
- Add a backend/order notification workflow and payment integration only after the cafe approves the operational process.
- Update social links and map pin if needed.

All ordering and checkout behavior is currently local frontend demo behavior. No backend, database, authentication, payment or real order submission is implemented.
